# Recovery Objectives Policy

## Overview
Defines canonical Service Level Objectives (SLOs) and recovery metrics thresholds:
- **RTO (Recovery Time Objective)**: <= 15 minutes (900 seconds)
- **RPO (Recovery Point Objective)**: <= 5 minutes (300 seconds)
- **MTTD (Mean Time to Detect)**: <= 1 minute (60 seconds)
- **MTTA (Mean Time to Acknowledge)**: <= 5 minutes (300 seconds)
- **MTTR (Mean Time to Recover)**: <= 15 minutes (900 seconds)

## Truthfulness Rule
Objectives are marked as compliant ONLY when supported by empirical runtime evidence.
