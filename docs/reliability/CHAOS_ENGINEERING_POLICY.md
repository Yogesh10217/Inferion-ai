# Chaos Engineering Policy

## Overview
Governs controlled chaos experiments, execution modes, state machine transitions, and safety boundaries.

## 16 Canonical Failure Types
1. `APPLICATION_CRASH`
2. `DATABASE_UNAVAILABLE`
3. `DATABASE_LATENCY`
4. `CACHE_UNAVAILABLE`
5. `CACHE_LATENCY`
6. `NETWORK_LATENCY`
7. `NETWORK_PARTITION`
8. `DEPENDENCY_FAILURE`
9. `CONTAINER_RESTART`
10. `CONTAINER_UNAVAILABLE`
11. `RESOURCE_EXHAUSTION`
12. `CPU_PRESSURE`
13. `MEMORY_PRESSURE`
14. `CONNECTION_POOL_EXHAUSTION`
15. `TIMEOUT_FAILURE`
16. `SECURITY_DEPENDENCY_FAILURE`

## Chaos State Machine Lifecycle
`CREATED` → `VALIDATING` → `AUTHORIZED` → `RUNNING` → `FAILURE_INJECTED` → `OBSERVING` → `RECOVERING` → `VALIDATING_RECOVERY` → `COMPLETED`

Terminal failure states: `BLOCKED`, `FAILED`, `ABORTED`, `RECOVERY_FAILED`.
